

📊 Sales Performance Dashboard (Tableau)

This dashboard provides a comprehensive comparison of sales performance across two selected regions.
 Management will be able to compare total sales, average 
sales per order, the number of customers, the number of orders, and the number 
of products sold in each region. This will enable the organization to make informed 
decisions, identify improvement areas, and implement effective sales strategies.

Features

- Compare two regions simultaneously.
- Interactive region selection using dropdown filters.
- KPI cards displaying:
  - Total Sales
  - Average Sales per Order
  - Number of Orders
  - Number of Customers
  - Products Sold
- Sales by Category visualization.
- Top 5 Sub-Category Sales comparison.
- Clean and user-friendly dashboard layout.

  KPIs

| KPI | Description |
|------|-------------|
| Total Sales | Total revenue generated by the selected region |
| Average Sales per Order | Average revenue per order |
| Number of Orders | Total orders placed |
| Number of Customers | Total unique customers |
| Products Sold | Total quantity of products sold |


Dashboard Components
Regional Comparison
Compare the performance of:
- Primary Region
- Secondary Region

  Sales by Category
Displays sales across:
- Furniture
- Office Supplies
- Technology

## Tools & Technologies
- Tableau
